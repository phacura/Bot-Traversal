BotTraversal is an independent AI traversal system designed to overcome NavMesh limitations, improve movement across complex environments, and provide reliable navigation recovery.

It is developed to work alongside PIT Fireteam, allowing the two mods to handle different responsibilities without replacing each other’s functionality.

The current focus is friendly AI followers, while the long-term goal is to support all SPT bots, including PMCs, Scavs, Raiders, Rogues, Bosses, and modded AI.

Current Status: Beta — Active Development
